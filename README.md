# Superclim Empresas

Fundação técnica do site B2B da Superclim, criada com React 19, Vite, TypeScript, React Router e Tailwind CSS.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

O build estático é gerado em `dist/` e o projeto inclui configuração explícita para detecção e deploy no Vercel.
